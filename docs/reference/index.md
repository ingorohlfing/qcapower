# Package index

## All functions

- [`qcapower()`](qcapower.md) :

  Estimate power for a term in Qualitative Comparative Analysis (QCA).
  `qcapower` returns a power estimate with regard to the consistency of
  a term, given information about the required parameters

- [`qp_cases()`](qp_cases.md) : Calculte the number of cases for a
  particular case target based on simulated data

- [`qp_cases_brute()`](qp_cases_brute.md) : Calculate the number of
  cases for a particular case target with iterative simulations (brute
  force)

- [`qp_quant_plot()`](qp_quant_plot.md) : Sina plot of 5 distributions

- [`qp_run_plot()`](qp_run_plot.md) : Plot of power estimate against the
  number of simulations

- [`qp_sim_power`](qp_sim_power.md) : Data simulated power estimates

- [`qp_sina_data`](qp_sina_data.md) : Data simulated power estimates for
  plotting of 5%-quantiles
