# Data simulated power estimates

A dataset containing power simulations for different number of cases and
different values for null- and alternative hypothesis

## Usage

``` r
qp_sim_power
```

## Format

A dataframe with simulation parameters and calculated power

## Details

- cases:

  number of cases

- null_hypo:

  null hypothesis (H0)

- alt_hypo:

  alternative hypothesis

- sims:

  number of simulations

- perms:

  number of permutations

- perms:

  calculate power
